# Project Context

`otaviogonzaga.dev` is a personal portfolio for Otavio Gonzaga, presented primarily as a Software Engineer. The visual reference is the approved Figma design and the visual language is Gruvbox.

The application uses Next.js App Router, Bun, TypeScript, Tailwind, and module-first organization. Portuguese Brazilian is the default language and English is an explicit, cookie-persisted alternative. Blog and administration features are future scope and must not be implemented early.
